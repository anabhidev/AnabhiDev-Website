Setup Dua Akun
Claude Code

Panduan memisahkan akun kantor & akun pribadi di Claude Code — supaya kuota nggak ketuker lagi seperti kejadian kemarin. Mencakup panel sidebar extension dan terminal CLI, karena keduanya butuh solusi yang berbeda.

VS Code + VS Code Insiders CLAUDE_CONFIG_DIR v1.1 · 27 August 2026
🔍

Kenapa Akun Bisa Kesedot

Kejadian kemarin — buka 2 VS Code, satu akun kantor satu akun pribadi, terus akun kantor ikut ketuker jadi akun pribadi — itu bukan bug. Ini konsekuensi langsung dari cara Claude Code menyimpan data login.

1
Satu folder config = satu identitas. Secara default, Claude Code menyimpan kredensial, riwayat sesi, plugin, dan pengaturan di satu folder yang sama: %USERPROFILE%\.claude. Tidak peduli berapa window VS Code yang kamu buka — semuanya baca dari folder yang sama itu.
2
Login baru = menimpa, bukan menambah. Waktu kamu login akun pribadi di VS Code kedua, dia menulis ulang isi folder .claude itu. VS Code pertama yang masih terbuka otomatis ikut baca identitas baru — makanya kuota pribadi yang kepakai padahal kamu kerja di project kantor.
3
Panel sidebar dan terminal itu dua hal berbeda. Panel chat visual (yang kamu screenshot kemarin) ternyata punya CLI bawaan sendiri di dalam extension-nya — bukan langsung pakai command claude yang di terminal. Ini penting, karena solusi yang bekerja untuk terminal belum tentu bekerja untuk panel. Detail di bagian 3 Skenario di bawah.
🎛️

3 Skenario Pemakaian Claude Code

Cara kamu pakai Claude Code menentukan solusi mana yang relevan. Cek dulu kamu yang mana — kemarin kamu pakai panel sidebar (screenshot yang dikirim), jadi fokus utama panduan ini ada di skenario 1.

Skenario Cara pakai Bisa dipisah pakai CLAUDE_CONFIG_DIR? Solusi yang bekerja
1. Panel Sidebar
Kasus kamu kemarin		 Klik ikon Claude Code di sidebar VS Code, chat muncul di panel samping (seperti screenshot kamu) TIDAK — panel selalu baca akun default, tidak mewarisi environment variable apa pun Aplikasi terpisah — VS Code Insiders untuk akun kedua
2. Terminal CLI Buka Terminal di VS Code, ketik claude langsung dari command line YA — env var terbaca normal di sesi terminal CLAUDE_CONFIG_DIR + function PowerShell
3. Kombinasi Pakai panel untuk kerjaan visual, sesekali buka terminal untuk fitur CLI-only (mis. --add-dir, MCP config) Sebagian — tergantung yang mana yang lagi dipakai Kombinasi keduanya: VS Code Insiders (utama) + CLAUDE_CONFIG_DIR di terminal-nya (cadangan)
Kenapa panel nggak bisa dipisah pakai env var? Karena extension Claude Code "membundel" salinan CLI-nya sendiri untuk menggerakkan panel chat. Salinan ini tidak membaca environment variable dari sesi terminal manapun — dia selalu jalan dengan konfigurasi akun default milik VS Code yang menjalankannya. Satu-satunya cara memisahkannya adalah menjalankan di aplikasi/instalasi VS Code yang benar-benar terpisah.
📦

Installer vs System Installer vs .zip (Portable) vs Insiders

Soal pertanyaan kamu "yang mana yang portable" — jawabannya: di halaman download resmi VS Code, opsi .zip itulah versi portable-nya. Tidak ada tombol bertuliskan "Portable" secara eksplisit. Berikut breakdown semua opsi yang ada:

Opsi Kelebihan Kekurangan Cocok untuk kasus kamu?
User Installer Install standar, tidak butuh admin, auto-update jalan normal Data tersimpan di %APPDATA% — satu install = satu identitas, tidak otomatis terpisah Tidak cukup sendirian — ini yang kamu pakai sekarang untuk kantor
System Installer Sama seperti User Installer, tapi ter-install untuk semua user di komputer (butuh admin) Sama seperti User Installer — tetap satu identitas per instalasi Tidak relevan untuk kasus dual-account single-user
.zip (Portable) Extract ke folder manapun, semua data (extension, settings, kredensial) nempel di folder itu sendiri — gampang dipindah/backup. 100% gratis, tidak perlu install ulang apa pun Tidak auto-update — update manual dengan ganti isi .exe, sisakan folder data. Perlu bikin folder data manual dulu Bisa dipakai — alternatif kalau nggak mau install apa pun tambahan
VS Code Insiders Installer resmi Microsoft, terpisah otomatis dari VS Code Stable (icon, folder data, extension, kredensial semua beda) sejak awal — tanpa langkah manual apa pun. Auto-update tetap jalan normal Ini "preview build" — dapat fitur terbaru duluan, jarang ada masalah stabilitas tapi bukan versi paling teruji Direkomendasikan — paling simpel & paling minim risiko salah setup
CLI (Command Line) Untuk automasi/scripting, bukan untuk penggunaan editor sehari-hari Bukan aplikasi ber-UI — tidak relevan untuk kasus kamu Tidak relevan

Link download resmi

  • VS Code (Stable, sudah kamu pakai) — code.visualstudio.com/download
  • VS Code Insiders — code.visualstudio.com/insiders

Rekomendasi Final

Karena kamu pakainya lewat panel sidebar, solusi yang benar-benar bekerja adalah aplikasi terpisah — bukan env var. Rekomendasinya:

🏢
VS Code (Stable) — akun kantor. Tetap seperti sekarang, tidak disentuh sama sekali. Login akun kantor tetap di situ.
🏠
VS Code Insiders — akun pribadi. Install baru, login akun pribadi di situ. Karena Insiders 100% terpisah datanya dari Stable sejak awal (bukan hasil konfigurasi manual), panel sidebar Claude Code di masing-masing aplikasi akan otomatis baca akun yang berbeda.
Bonus opsional: kalau nanti kamu juga sering pakai terminal CLI (bukan cuma panel), kita tambahkan CLAUDE_CONFIG_DIR di kedua aplikasi itu juga — supaya kalau suatu saat buka terminal di VS Code Insiders, otomatis tetap kebaca akun pribadi, bukan malah nyasar baca folder .claude default. Langkahnya ada di bagian Setup Terminal CLI di bawah — sifatnya tambahan, tidak wajib kalau kamu memang cuma pakai panel.
1

Install VS Code Insiders

1
Download installer

Buka code.visualstudio.com/insiders di browser. Pilih Windows (User Installer, x64) — sama seperti waktu kamu download VS Code biasa.

2
Jalankan installer

Klik dua kali file .exe yang barusan didownload. Next-next seperti install software biasa. Tidak perlu ubah lokasi instalasi default.

3
Buka VS Code Insiders

Setelah selesai install, cari "Visual Studio Code Insiders" di Start Menu (ikon hijau, beda dari VS Code biasa yang biru). Buka.

4
Install extension Claude Code

Di VS Code Insiders yang baru dibuka: klik ikon Extensions di sidebar kiri (atau Ctrl+Shift+X) → cari "Claude Code" → Install. Ini instalasi baru, terpisah total dari extension yang ada di VS Code kantor kamu.

Sampai step ini, belum ada risiko apa pun ke VS Code kantor kamu — kita baru install aplikasi baru yang kosong.
2

Login Akun Pribadi di Insiders

1
Buka panel Claude Code

Di VS Code Insiders, klik ikon Claude Code di sidebar kiri (ikon bintang/spark, sama seperti di VS Code kantor kamu).

2
Login dengan akun pribadi

Panel akan minta login. Browser terbuka otomatis → pilih/masukkan akun pribadi kamu (bukan akun kantor). Selesaikan proses OAuth di browser, lalu kembali ke VS Code Insiders.

3
Selesai — cek sekilas

Panel Claude Code di VS Code Insiders sekarang terikat ke akun pribadi. Panel Claude Code di VS Code kantor (yang lama) tetap terikat ke akun kantor — keduanya boleh terbuka bersamaan, tidak akan saling menimpa lagi karena masing-masing aplikasi punya folder data sendiri-sendiri.

Kalau nanti perlu ganti akun lagi (misal mau login ulang atau ganti ke akun lain), lakukan hanya di dalam aplikasi VS Code yang bersangkutan. Jangan login akun baru di VS Code Insiders sambil berharap itu mengubah akun di VS Code Stable — itu justru skenario yang ingin kita hindari.
3

CLAUDE_CONFIG_DIR untuk Terminal (Opsional)

Bagian ini hanya perlu kalau kamu juga sering buka terminal di VS Code dan ketik claude langsung (bukan cuma klik panel). Kalau kamu 100% pakai panel saja, bagian 1–2 di atas sudah cukup — boleh lewati bagian ini.

1
Cek Claude Code CLI terdeteksi

Buka PowerShell (bisa dari Start Menu, atau dari terminal terintegrasi di VS Code manapun).

claude --version

Kalau muncul nomor versi, lanjut ke step berikutnya.

2
Buat folder config baru khusus akun pribadi
New-Item -ItemType Directory -Force "$HOME\.claude-personal"

Akun kantor tetap di folder default %USERPROFILE%\.claude — tidak disentuh sama sekali, jadi session, skills, dan plugin kantor kamu aman.

3
Buka PowerShell profile
notepad $PROFILE

Kalau muncul dialog "file belum ada", pilih Yes untuk membuatnya.

4
Tambahkan function claude-personal

Di Notepad yang terbuka, tempel baris berikut, lalu simpan (Ctrl+S) dan tutup:

function claude-personal {
    $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-personal"
    claude @args
}

Tutup PowerShell yang lama, lalu buka PowerShell baru supaya function ini aktif.

Batasan penting yang perlu kamu tahu: Claude Code di Windows tidak hanya menyimpan data di folder .claude\, tapi juga menulis sebagian state ke file %USERPROFILE%\.claude.json — file ini di luar folder yang di-set oleh CLAUDE_CONFIG_DIR. Kalau dua sesi terminal jalan bersamaan dari home directory Windows yang sama, ada kemungkinan kecil state ini tetap "nyenggol" satu sama lain. Untuk kredensial login sendiri, ini aman — tapi kalau kamu mau isolasi 100% total tanpa risiko sama sekali, jalankan claude-personal selalu dari terminal di VS Code Insiders (bukan dari terminal di VS Code Stable), supaya dua-duanya juga terpisah secara aplikasi.
4

Login via Terminal

1
Jalankan function yang baru dibuat
claude-personal

Claude Code akan mendeteksi folder .claude-personal masih kosong dan meminta login dari awal.

2
Login dengan akun pribadi

Browser terbuka otomatis → login dengan akun pribadi kamu, sama seperti biasa.

3
Selesai — kredensial tersimpan permanen

Mulai sekarang, cukup ketik claude-personal tiap kali mau pakai akun pribadi di terminal. Tidak perlu login ulang lagi. Ketik claude biasa (tanpa embel-embel) untuk tetap pakai akun kantor seperti biasa.

🔎

Verifikasi Akhir

Sebelum kamu percaya setup ini beres, cek dulu dengan langkah berikut:

1
Buka kedua aplikasi bersamaan

VS Code (Stable) untuk project kantor, VS Code Insiders untuk project pribadi. Buka dua-duanya di layar yang sama.

2
Cek status akun di masing-masing panel

Di kolom chat panel Claude Code, ketik:

/status

Lakukan di kedua aplikasi. Pastikan email/akun yang tertampil berbeda antara VS Code (kantor) dan VS Code Insiders (pribadi).

3
Test generate barengan

Coba minta Claude generate sesuatu yang kecil di kedua panel secara bersamaan (simulasi kejadian kemarin). Cek lagi /status di masing-masing setelahnya — kalau akunnya tetap konsisten (tidak ketuker), setup berhasil.

Troubleshooting

?
Panel di VS Code Insiders minta login ulang terus-menerus. Kemungkinan kredensial belum tersimpan dengan benar. Coba /logout lalu /login ulang di panel tersebut. Pastikan tidak ada proses VS Code Insiders lain yang masih berjalan di background saat login (cek Task Manager).
?
Akun tetap ketuker walau sudah pakai VS Code Insiders. Pastikan kamu benar-benar membuka aplikasi Insiders (ikon hijau), bukan window VS Code Stable yang kedua (ikon biru). Dua window dari aplikasi yang sama tetap berbagi satu folder data — yang memisahkan adalah aplikasinya, bukan jumlah window-nya.
?
Terminal claude-personal tidak dikenali sebagai command. Pastikan sudah menutup semua jendela PowerShell lama dan buka yang baru setelah mengedit $PROFILE. Kalau masih gagal, cek isi profile dengan notepad $PROFILE — pastikan function-nya benar-benar tersimpan.
?
Mau pindah ke .zip Portable, bukan Insiders. Bisa — download .zip dari halaman download resmi, extract ke folder pilihan kamu (misal D:\VSCode-Personal), lalu buat folder kosong bernama persis data tepat di sebelah Code.exe. Setelah itu install extension Claude Code seperti biasa dan login — semua data otomatis kesimpan di folder data itu, terpisah dari instalasi VS Code manapun.
