Cara Pakai Mockup
Quiz Import

Panduan singkat ini menjelaskan cara mencoba mockup (simulasi/prototipe) fitur Import Soal Quiz dari Google Spreadsheet, sebelum fitur ini benar-benar dibangun di LMS.
This short guide explains how to try the Quiz Import mockup (simulation/prototype) before the feature is actually built into the LMS.

Apa Itu Mockup Ini?

What is this mockup?

Mockup adalah simulasi/prototipe yang benar-benar berjalan — bukan sekadar gambar atau screenshot. Semua tombol bisa diklik, semua validasi soal quiz benar-benar diperiksa, semua yang terjadi di layar itu real. Bedanya dengan LMS asli hanya satu: data-nya masih dummy (contoh), belum tersambung ke database LMS yang sesungguhnya.

A mockup is a simulation/prototype that actually runs — not a picture or screenshot. Every button works, every quiz question is genuinely validated. The only difference from the real LMS: the data is still dummy (sample), not yet connected to the actual LMS database.

Kenapa dibuat sebagai mockup dulu? — Why build a mockup first?

Supaya alur dan aturan pemeriksaan soal (validasi) bisa dicoba dan disepakati bersama SEBELUM masuk ke sistem LMS yang asli — supaya tidak ada data quiz staff yang rusak saat fitur ini nanti benar-benar dipakai.

So the flow and question-checking rules (validation) can be tried and agreed upon BEFORE going into the real LMS system — to make sure no real staff quiz data gets damaged once this feature is actually used.

Apa yang bisa dicoba — What you can try

  • Upload file CSV — parsing (pembacaan) datanya sungguhan, bukan simulasi. / CSV upload — the parsing is genuinely real, not simulated.
  • Pemeriksaan otomatis (validation) — soal kosong, kunci jawaban salah, soal duplikat, semuanya benar-benar dideteksi. / Automatic validation — blank questions, wrong answer keys, duplicate questions are all genuinely detected.
  • Preview database sebelum-sesudah — melihat persis apa yang akan tersimpan. / Before/after database preview — see exactly what would be saved.

Apa yang BELUM terjadi — What does NOT happen yet

  • Tidak ada data yang benar-benar tersimpan ke LMS. / No data is actually saved to the LMS.
  • Link Google Spreadsheet sungguhan belum bisa dibaca langsung (baru simulasi). / A real Google Spreadsheet link cannot be read directly yet (simulated only).
  • Semua yang terjadi di mockup hilang setiap refresh halaman — memang seperti itu. / Everything in the mockup resets on every page refresh — that is expected.

5 Langkah Pakai Mockup

5 Steps to Use the Mockup

1
Pilih Course & Sumber Data — Choose Course & Source
Di bagian atas, pilih Target Course dari dropdown. Lalu pilih salah satu dari 3 tab: 🔗 Spreadsheet Link, 📄 Upload CSV, atau 🎲 Load Sample Data.
At the top, choose a Target Course from the dropdown. Then pick one of 3 tabs: Spreadsheet Link, Upload CSV, or Load Sample Data.
💡 Untuk mencoba paling cepat: klik tab 🎲 Load Sample Data lalu tombol Load Sample (with errors). / Fastest way to try: click the Load Sample Data tab, then the "Load Sample (with errors)" button.
2
Cek Column Detection — Check Column Detection
Sistem otomatis mencocokkan nama kolom di file dengan skema database (bukan berdasarkan urutan kolom). Kalau ada kolom wajib yang hilang, akan muncul pemberitahuan merah dan langkah berikutnya terkunci.
The system automatically matches column names in the file to the database schema (not by column order). If a required column is missing, a red notice appears and the next step stays locked.
3
Lihat Validation & Preview
Setiap baris soal ditandai OK, WARN, atau ERROR. Klik chip filter di atas tabel untuk melihat baris tertentu saja. Kolom Issues menjelaskan tepatnya apa yang salah di baris itu.
Every question row is marked OK, WARN, or ERROR. Click the filter chips above the table to see only certain rows. The Issues column explains exactly what is wrong with that row.
4
Pilih Import Mode
Append menambahkan soal baru tanpa mengubah yang lama. Replace All mengganti seluruh soal course itu — centang/hilangkan "course ini sudah ada attempts" untuk melihat bedanya (dinonaktifkan vs dihapus permanen).
Append adds new questions without touching old ones. Replace All replaces the whole question set — tick/untick "this course already has attempts" to see the difference (deactivated vs permanently deleted).
5
Klik Run Import & Lihat Hasilnya
Setelah ✓ Run Import diklik, panel Database Preview menampilkan tab Before dan After — persis seperti apa isi sheet QuizQuestions sebelum dan sesudah. Ada juga Activity Log di bagian bawah.
After clicking Run Import, the Database Preview panel shows Before and After tabs — exactly what the QuizQuestions sheet looks like before and after. There is also an Activity Log below.

3 Skenario Wajib Dicoba

3 Scenarios You Should Try

Skenario 1
🎲 Load Sample (with errors)
Muat 14 soal contoh yang sengaja berisi semua jenis masalah — kosong, kunci jawaban salah, duplikat, dll. / Load 14 sample questions deliberately containing every kind of problem — blanks, wrong answer keys, duplicates, etc.
✓ Yang diharapkan: 3 error, 4 warning, 6 valid, 1 baris kosong diabaikan. / Expect: 3 errors, 4 warnings, 6 valid, 1 blank row ignored.
Skenario 2
♻ Replace All + Attempts
Pilih mode Replace All, centang "course ini sudah ada attempts", lalu Run Import. / Choose Replace All mode, tick "this course already has attempts", then Run Import.
✓ Yang diharapkan: soal lama muncul di tab Before dengan status TRUE, di tab After statusnya jadi FALSE (dicoret) — bukan hilang. / Expect: old questions appear TRUE in the Before tab, FALSE (struck through) in After — not gone.
Skenario 3
⬇ Download Error Report
Setelah preview muncul, klik "Download Error Report" di bagian bawah tabel. / After the preview appears, click "Download Error Report" at the bottom of the table.
✓ Yang diharapkan: file CSV berisi daftar baris bermasalah beserta alasannya, siap dikirim balik ke HoD. / Expect: a CSV file listing problem rows and their reasons, ready to send back to the HoD.

FAQ

Frequently Asked Questions

Apakah ini mengubah data LMS yang asli? — Does this change the real LMS data?
Tidak. Mockup ini berdiri sendiri (standalone), tidak tersambung ke server atau database LMS mana pun. Semua "database" yang terlihat di mockup adalah data contoh yang hanya ada di browser kakak saat ini. / No. This mockup is standalone — it is not connected to any LMS server or database. Any "database" seen in the mockup is sample data that only exists in your browser right now.
Kenapa ada tulisan "Mockup" di bagian atas halaman? — Why does it say "Mockup" at the top?
Supaya jelas bagi siapa pun yang membukanya bahwa ini masih tahap simulasi/uji coba, bukan fitur yang sudah aktif di LMS. / So anyone opening it understands this is still a simulation/testing stage, not a feature that is already live in the LMS.
Kalau saya refresh halaman mockup, apa yang terjadi? — What happens if I refresh the mockup page?
Semua yang sudah dicoba (soal yang di-import, perubahan database dummy) akan kembali ke kondisi awal. Ini normal — mockup memang tidak menyimpan apa pun secara permanen. / Everything tried so far (imported questions, dummy database changes) resets to the starting state. This is normal — the mockup is not meant to save anything permanently.
Bolehkah saya coba upload spreadsheet asli dari course saya? — Can I try uploading my actual course spreadsheet?
Boleh, dan justru dianjurkan. Export dulu jadi CSV (Google Sheets → File → Download → Comma Separated Values), lalu drag file itu ke tab 📄 Upload CSV di mockup. Hasilnya akan menunjukkan persis mana soal yang lolos dan mana yang perlu diperbaiki. / Yes, and it is encouraged. Export it as CSV first (Google Sheets → File → Download → Comma Separated Values), then drag that file into the "Upload CSV" tab in the mockup. The result will show exactly which questions pass and which need fixing.
Setelah mockup ini disetujui, kapan fitur aslinya jadi? — After this mockup is approved, when will the real feature be ready?
Fitur asli dikembangkan setelah alur dan aturan validasi di mockup ini disepakati bersama. Perkiraan dan jadwal pengembangan akan diinformasikan terpisah oleh IT Department. / The real feature will be developed once the flow and validation rules in this mockup are agreed upon together. Development estimates and schedule will be communicated separately by the IT Department.
