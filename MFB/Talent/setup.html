☁️ Mengapa Cloudflare Pages Sangat Ideal untuk Miss Fish Bali?
Dibandingkan Cloudflare Workers biasa, Cloudflare Pages adalah solusi Jamstack all-in-one yang dirancang untuk web multi-halaman berkinerja tinggi.
1
Koneksi Otomatis ke GitHub (Auto CI/CD)
Setiap kali Anda melakukan git push ke branch main, Cloudflare Pages otomatis membangun dan memperbarui website secara global dalam waktu kurang dari 15 detik tanpa perlu script rilis manual.
2
Kekuatan Serverless Worker Sudah Termasuk (Pages Functions)
Semua file di dalam folder /functions/api/ otomatis dijalankan sebagai Cloudflare Worker di edge. Anda mendapatkan backend serverless untuk Gemini & ClickUp dalam satu repositori yang sama!
3
Parameter Build Resmi Cloudflare Pages
Saat menambahkan project baru di Dashboard Cloudflare Pages (Create a project > Connect to Git), gunakan parameter berikut:
Framework preset       : None
Build command          : (kosongkan)
Build output directory : .
Root directory         : /
4
Custom Domain Miss Fish Bali
Setelah terhubung, masuk ke Custom domains di Cloudflare Pages dan tambahkan misalnya: career.missfishbali.com atau talent.missfishbali.com. Sertifikat SSL akan aktif otomatis secara gratis.
✨ Google Gemini AI Configuration & Live Tester
Gemini digunakan untuk AI CV Batch Screener, Smart Interview Studio, dan Laporan Intelligence Rekrutmen Eksekutif.
1
Dapatkan API Key dari Google AI Studio
Kunjungi Google AI Studio (aistudio.google.com) > Login dengan akun Google > Klik "Create API key" > Salin key yang berawalan AIzaSy....
2
Dukungan Multi-Key Rotation
Untuk menghindari limit rate 429 pada jam sibuk, Anda dapat memasukkan hingga 3 API Key (GEMINI_API_KEY, GEMINI_API_KEY_2, GEMINI_API_KEY_3). Sistem akan otomatis berpindah kunci jika kuota habis.
⚡ Interactive Live Tester: Google Gemini AI
Key Anda hanya diuji langsung dari browser ke API Google dan tidak disimpan di server pihak ketiga.
📋 ClickUp REST API v2 Configuration & Live Tester
ClickUp bertindak sebagai System of Record rekrutmen. Setiap pelamar baru disinkronkan menjadi task di List Rekrutmen.
1
Dapatkan Personal API Token
Buka ClickUp > Klik avatar profil di sudut kiri bawah > Settings > Apps > Klik "Generate Personal API Key" > Salin token (dimulai dengan pk_...).
2
Dapatkan Recruitment List ID
Buka Space Rekrutmen Miss Fish Bali > Klik icon titik tiga ... pada List "Talent Acquisition" > Copy link. Angka di akhir URL (misal: https://app.clickup.com/9018.../v/li/901802341234) adalah List ID Anda.

📅 Google Calendar Integration & Live Preview
Menampilkan agenda wawancara kandidat, food tasting Chef Carlos Barvo, dan trial shift secara terpadu di HR Dashboard.
1
Dapatkan Google Calendar ID
Buka Google Calendar > Pada menu kalender HR Miss Fish Bali di sebelah kiri, klik titik tiga > Settings and sharing > Gulir ke bagian "Integrate calendar" > Salin Calendar ID (bisa berupa email kalender atau kode alfanumerik panjang) atau Public URL.
2
Pastikan Izin Akses Tepat
Di bagian Access permissions for events, centang "Make available to public" (atau bagikan ke akun email tim rekrutmen Miss Fish Bali) agar iframe kalender dapat dirender dengan mulus.

⚡ Cloudflare Environment Variables & Secrets Generator
Hasilkan snippet konfigurasi yang siap Anda salin ke Cloudflare Pages Dashboard (Settings > Environment variables) atau terminal Wrangler.
# Cloudflare Pages Environment Variables (Production)
GEMINI_MODEL="gemini-1.5-flash"
GEMINI_API_KEY="AIzaSy..."
GEMINI_API_KEY_2=""
CLICKUP_API_BASE="https://api.clickup.com/api/v2"
CLICKUP_API_TOKEN="pk_..."
CLICKUP_RECRUITMENT_LIST_ID="901802341234"
GOOGLE_CALENDAR_ID="talent@missfishgroup.com"
TIMEZONE="Asia/Makassar"
BRAND_NAME="Miss Fish Bali"
Perintah Terminal Wrangler CLI (Jika Deploy via CLI):
npx wrangler pages secret put GEMINI_API_KEY
npx wrangler pages secret put CLICKUP_API_TOKEN
npx wrangler pages secret put CLICKUP_RECRUITMENT_LIST_ID
