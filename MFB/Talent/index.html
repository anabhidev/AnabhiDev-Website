ClickUp Parameters Required
Master Specification v1.1 · Section 29 Checklist

Before connecting the live backend to ClickUp API, the following parameters must be confirmed and configured:

1. Workspace ID: Team workspace identifier (e.g. 12345678)
2. Recruitment List ID: The ATS List ID where applicant tasks are collected.
3. ClickUp Form URL / ID: Used for candidate public job application CTA.
4. Task Status Schema: Exact statuses (e.g. New, Screening, Interview, Hired).
5. Custom Fields Mapping: Phone, Email, Position, Experience, Portfolio.
6. CLICKUP_API_TOKEN: Configured only in Cloudflare Pages / Workers secrets.
Serverless API Contract
Master Specification v1.1 · Section 10 Proposed API Layer
GET /api/jobs - Returns active open positions for public site
GET /api/applicants - Authenticated HR endpoint for applicant list
GET /api/applicants/:id - Detailed candidate info & CV metadata
GET /api/dashboard - Recruitment KPI aggregation
PATCH /api/applicants/:id/status - Updates status in ClickUp
POST /api/applicants/:id/notes - Posts internal interview note

All responses are sanitized server-side to prevent sensitive PII leakage and ClickUp internal metadata exposure.
