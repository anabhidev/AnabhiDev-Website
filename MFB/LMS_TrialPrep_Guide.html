Admin Task · #1

Ganti ID admin dari MF0001

MF0001 sekarang terdaftar sebagai IT Super Admin, tapi ID itu bukan milik kakak. Urutan di bawah WAJIB diikuti — jangan menurunkan MF0001 sebelum akun baru terbukti bisa login.

Sebelum mulai: File → Make a copy pada spreadsheet LMS. Ini jaring pengaman kakak kalau ada langkah yang meleset.
1

Salin spreadsheet

Buka Google Sheets LMS → File → Make a copy. Kerjakan semua langkah di bawah pada salinan ini dulu, bukan langsung di data asli — kecuali kakak sudah yakin.

2

Login sebagai MF0001

Pastikan masih bisa masuk dengan akun lama sebelum menyentuh apa pun.

3

Buat akun admin baru untuk diri sendiri

Menu Users → Add User. Isi ID employee kakak yang sebenarnya, role IT_ADMIN.

Penting: jangan isi password langsung di sheet. Kolom password menyimpan hash SHA-256, bukan teks biasa — mengetik password di sheet akan membuat akun itu tidak bisa login sama sekali. Password default otomatis dibuat sistem saat Add User dari UI.
4

Logout, coba login dengan ID baru

Berhenti di sini kalau gagal. Jangan lanjut ke langkah 5 sebelum akun baru terbukti bisa masuk dan punya akses admin penuh.

5

Ubah CONFIG.IT_ADMIN_ID di Code.gs

Baris ini menentukan siapa "pemilik sistem" di beberapa fungsi (penerbit sertifikat, kontak error). Ganti nilainya jadi ID kakak:

var CONFIG = { ... IT_ADMIN_ID : 'MF0001', ← ganti ke ID kakak ... };
6

Ubah role MF0001 ke peran yang sebenarnya

Kalau MF0001 memang orang lain di perusahaan, edit user itu lewat menu Users — ganti role dan department sesuai jabatan aslinya. Jangan dihapus; menghapus user bisa merusak relasi data (Progress, Certificates) yang menunjuk ke ID itu.

Admin Task · #2

Boleh punya 2-3 IT Super Admin

Tidak ada batasan di kode — role IT_ADMIN hanyalah nilai di satu kolom, bukan slot terbatas. Boleh dan disarankan punya cadangan, supaya lupa password satu orang tidak mengunci seluruh sistem.

Terverifikasi: tidak ada kode yang membatasi jumlah user dengan role IT_ADMIN. Bisa 1, 2, 3, atau lebih — sistem memperlakukan semuanya setara.

Cara membuat admin cadangan

1

Users → Add User

Isi data orang kedua (atau ketiga) yang dipercaya — biasanya rekan IT lain, atau Owner/GM kalau perlu jalur darurat.

2

Role = IT_ADMIN

Sama seperti admin utama. Tidak ada perbedaan hak akses antar sesama IT_ADMIN.

3

Simpan kredensial di tempat aman terpisah

Password manager, atau kertas dalam brankas kantor — bukan di chat WhatsApp. Ini akun cadangan, jadi harus benar-benar bisa diandalkan saat darurat.

4

Uji login berkala

Sesekali coba login dengan akun cadangan untuk memastikan masih berfungsi — bukan cuma dibuat lalu dilupakan.

Saran tambahan: kalau salah satu admin resign atau pindah divisi, ganti role akun itu ke non-admin (bukan dihapus) — supaya jejak riwayatnya tetap ada di Activity Log, tapi akses admin sudah tidak aktif.
Admin Task · #3

Tambah user baru untuk trial

Semuanya lewat UI Add User — jangan mengetik langsung ke sheet Users.

Kenapa tidak boleh diketik di sheet: kolom password menyimpan hash SHA-256. Mengetik abc123 langsung ke sheet berarti sistem akan membandingkan hash dari abc123 dengan teks abc123 mentah — tidak akan pernah cocok. User itu tidak bisa login.
1

Buka Users → Add User

Isi field yang diminta:

FieldContoh
user_idMF0010
usernamerian.f
emailrian@missfishbali.com
full_nameRian Febriana
roleSTAFF atau TRAINEE
departmentKitchen, Bar, dll — atau General
2

Password default dibuat otomatis

Sistem membuat password sementara dan menandai akun itu force_pw_change = TRUE.

Catatan penting: tanda "wajib ganti password" ini sudah ada di data — tapi layar yang MEMAKSA staff mengganti password sebelum masuk ke halaman lain belum dibangun di sisi tampilan. Untuk trial, staff akan tetap bisa login dan langsung masuk ke dashboard tanpa diminta ganti password. Ini bukan bug baru — memang belum sempat dikerjakan.
3

Assign course ke user baru

Menu Manage Courses → pilih course → Assign. Bisa per-user, per-departemen, atau per-role.

Sudah ada sejak v2.102: kalau course-nya berdepartemen beda dari staff yang dituju, akan muncul dialog konfirmasi otomatis — bukan galat, cuma memastikan kakak sengaja.
4

Bagikan kredensial ke 10 staff trial

Employee ID + password sementara. Sampaikan bahwa ini versi trial, bukan sistem final — sesuai pesan yang sudah kakak siapkan ke WAG sebelumnya.

Admin Task · #4 · Bisa dibagikan ke HR

Cara menambah modul video

Sistem menerima dua sumber: Google Drive atau YouTube. Halaman ini bisa dibagikan langsung ke tim HR.

Dua pilihan sumber video

SumberKapan dipakaiSetup wajib
Google DriveSOP internal, video training sensitifSharing: Anyone with the link → Viewer
YouTubeVideo umum, sudah ada channel perusahaanVisibility: Unlisted — lihat catatan di bawah
Wajib dibaca sebelum upload ke YouTube — istilah "Unlisted" vs "Unpublished":

YouTube TIDAK punya opsi bernama "Unpublished". Tiga pilihan visibility yang benar-benar ada: Public, Unlisted, dan Private.

Untuk video training internal: pilih Unlisted. Artinya video tidak muncul di pencarian YouTube maupun di halaman channel publik, tapi siapa pun yang punya link bisa menonton — termasuk tanpa login akun Google. Ini yang dibutuhkan supaya video bisa diputar embed di dalam LMS.

JANGAN pilih Private — video Private hanya bisa ditonton oleh akun Google yang secara spesifik diundang satu per satu oleh pemilik video. Video Private tidak akan bisa diputar di dalam LMS sama sekali, walau linknya benar.

1

Upload & atur visibility

Drive: klik kanan file → Share → ubah ke "Anyone with the link". YouTube: saat upload, di kolom Visibility pilih Unlisted — bukan Private, bukan Public.

2

Buka Manage Courses → pilih course → Add Module

Isi Title, pilih Type = Video.

3

Pilih Source Type

Ada toggle GDRIVE / YOUTUBE di form. Sistem otomatis mengecek — kalau kakak paste link YouTube tapi Source Type masih GDRIVE, akan muncul pesan "This looks like a YouTube URL. Please change Source Type to YouTube."

4

Paste URL, isi durasi

Cukup paste link biasa (share link Drive, atau URL video YouTube) — sistem yang mengekstrak ID-nya sendiri.

5

Atur ambang penyelesaian (opsional)

Field min_watch_pct, default 95%. Artinya staff harus menonton minimal 95% durasi video sebelum modul dianggap selesai. Video tidak bisa dipercepat, dan berpindah tab otomatis menjeda video.
